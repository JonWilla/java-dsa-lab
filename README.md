# Java DSA Lab

A hands-on Java project for implementing and testing fundamental data structures and algorithms.

## Project Goals

- Strengthen Java programming skills
- Practice object-oriented programming
- Implement data structures from scratch
- Analyze time and space complexity
- Develop unit-testing and Git workflow skills
- Prepare for software engineering internships and technical interviews

## Planned Data Structures

- Queue
- Stack
- Linked list
- Binary search tree
- Hash table
- Graph

## Technologies

- Java 21
- IntelliJ IDEA
- Git
- GitHub

Project foundation in progress.
